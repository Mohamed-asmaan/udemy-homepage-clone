# Udemy Landing Page Clone

A UI recreation of Udemy's homepage for layout practice.

## 📌 Overview

This project replicates the structure and styling of the Udemy homepage.

It focuses on layout accuracy and visual hierarchy.

## 🛠 Tech Stack

- HTML5
- CSS3

## 🎯 Concepts Practiced

- Flexbox and grid layout
- Navigation bar structure
- Card grids
- Hero section layout
- Image handling
- Hover effects

## 🚀 How to Run

Open `index.html` in a browser.

No build tools required.
